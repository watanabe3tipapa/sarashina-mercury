Sarashina AI × PWA

Sarashina を、
あなたの手元で。

API キーひとつで動く国産 LLM の PWA クライアント。チャット・翻訳・RAG・Guard を、 サーバーに鍵を預けず、オフラインでも使える単一アプリにまとめました。

アプリを開く GitHub 設計ガイド
React 19 TypeScript Vite Tailwind CSS v4 PWA
01

4 つの営みを、ひとつのアプリに

対話する・翻訳する・根拠を探す・安全を確かめる。Sarashina のモデル群を、日常の言葉で使える UI にしました。

対話する

sarashina3-mini / nano を切り替えられるストリーミングチャット。Markdown と GFM をそのまま描画します。

Chat Completions

翻訳する

方向（日→英 / 英→日）とトーン（business-formal / business-casual / technical / marketing）を指定した、文脈を汲む翻訳。

Translate

根拠を探す

Embeddings と Rerank で文書を関連度順に並べ、引用元を本文からたどれる根拠付きの回答を返します。

Embeddings + Rerank

安全を確かめる

入力テキストの安全性を sarashina3-guard で判定。威圧せず、前向きな回復導線として提示します。

Guard

オフラインで使う

vite-plugin-pwa と Workbox によるインストール可能な PWA。端末のホーム画面からアプリとして起動できます。

Installable

鍵を持ち歩く

API キーはブラウザの localStorage にのみ保存。サーバーへは送らず、リクエストごとに直接利用します。

Data sovereignty

03

UX/UI の設計原則

一

日本語の「間」を尊重する

省略や婉曲を前提とし、完全な文の強制より意図の補完を支援します。

二

敬語レベルを可視化する

丁寧語・謙譲語・尊敬語のトーンを選択し、翻訳の前にプレビューできます。

三

遅延を設計する

ストリーミング表示と進行状況の可視化で、待機の不安を軽減します。

四

安全性の透明性を保つ

Guard の判定は威圧的でなく、前向きな回復導線として提示します。

05

はじめ方

1

リポジトリを取得する

git clone https://github.com/watanabe3tipapa/sarashina-mercury.git
cd sarashina-mercury
pnpm install
2

開発サーバーを起動する

pnpm dev

起動後、アプリの「設定」から API キーを登録すると各機能が利用できます。

3

本番ビルドして公開する

pnpm build   # 型チェック + 本番ビルド → dist/

本番では CORS 回避のため Cloudflare Worker の URL を VITE_SARASHINA_API_BASE に設定します。

セキュリティ: API キーは localStorage に保存され、Sarashina API 以外へ送信されません。 公開端末での利用は避け、必要に応じてキーをローテーションしてください。
公開アプリの設定: GitHub Pages で公開したアプリを動作させるには、リポジトリの Settings → Secrets and variables → Actions → Variables で変数 SARASHINA_API_BASE に Cloudflare Worker の URL（例: https://sarashina-proxy.<your-subdomain>.workers.dev/v1）を設定してください。 ビルド時に VITE_SARASHINA_API_BASE として注入され、公開アプリから Sarashina API に到達できるようになります。 なお、実際に稼働しているプロキシの URL は本公開ページでは開示していません。各自の環境で用意してください。
